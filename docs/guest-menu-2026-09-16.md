# Гостевое меню: утверждённые макеты, 16 сентября 2026

Реализовано локально, не опубликовано.

- От 1280 px: категории слева, три колонки карточек, избранное справа.
- Ниже 1280 px: боковых панелей нет; категории открываются через «Все разделы» или верхние ссылки, меню и избранное переключаются нижней навигацией. Это также относится к десктопу с открытыми DevTools.
- На телефоне — компактная сетка из двух колонок. Вино выводится строками с отдельными ценами бокала и бутылки; доступен общий переключатель карточки/список.
- По умолчанию тёмная тема независимо от системной; переключатель сохраняет светлую или тёмную тему в `barbar-guest-theme`.
- Избранное сохраняет только ключи `category:id` на текущем устройстве. Названия, изображения и цены берутся из свежего публичного меню; скрытые или удалённые позиции не показываются. Это список выбора, без заказа или записи продаж.
- Сохранены RU/EN/HY, реальный логотип, существующие фото, цены, QR-ссылка `/menu` и публичный API без сессии.
- При неудачном обновлении сохранённого меню явно показано, что цены могут устареть. Повторные запросы отменяют предыдущий; запрос ограничен 12 секундами.

## Разделение кода

`GuestMenu.tsx` компонует страницу и навигацию; `menu-parts.tsx` содержит карточки, цены, список категорий и избранное; `use-guest-menu.ts` читает публичный API; `use-guest-preferences.ts` хранит настройки и выбранные ID. Стили разделены на оболочку, каталог, панели и адаптив. Новые тексты с переводами находятся в `config/guest-menu.json`. Зависимости не добавлены; учёт, API и схема MongoDB не менялись.

## Проверки

- `npm run check`: ESLint, TypeScript, 164 модульных теста.
- `npm run build`: успешно.
- 4 Playwright-сценария гостевого меню и QR: работа без сессии, смена языка, обновление цен, дефолтная тёмная тема при светлой системной, сохранение темы/избранного, offline-предупреждение и повтор, категории и закрытие по Escape, scroll lock, бокал/бутылка, переключение списка, переход между узкой и широкой раскладкой.
- Проверки ширин 320, 390, 760, 1024, 1232 и 1440 px, включая армянские подписи: горизонтального переполнения нет; нижняя навигация и левая панель не отображаются одновременно.
- Визуально просмотрены десктоп, средняя ширина без боковой панели, мобильная сетка обеих тем и строки вина.

Новый функционал увеличил отдельный JS-чанк меню с 2,44 до 5,53 kB gzip, CSS с 3,15 до 4,65 kB gzip. Это не измерение ускорения. Новых изображений или библиотек нет; React и манифест фото остались общими отдельными чанками. Реальные мобильные устройства и production-публикация не проверялись.
