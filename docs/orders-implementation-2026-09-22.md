# Реализация гостевых заявок и закрытия смены — 22 сентября 2026

Изменения только в рабочей копии. Коммиты, публикация, рабочая БД, аутентификация и конфигурация агентов не менялись.

## Сделано

- Гостевой заказ по QR стола, корзина, стабильный токен повтора, отдельная коллекция заявок, явное истечение и серверные лимиты.
- Серверные цены и объёмы, окончательное частичное принятие, запрет принятия при смене цены, транзакционное списание и защита от повторов.
- Общая очередь заявок на доске и экране заказа, QR-карточки, лента и очередь Web Push обеим ролям.
- Закрытие смены с проверкой открытых заказов и показанных итогов, уникальным днём, аудитом и резервированием. Закрытый день блокирует новые продажи; оплаченный чек нельзя исправить через отмену продажи.
- Расчёты по дню открытия заказа с границей 06:00 Asia/Yerevan, средний чек, способы оплаты, история смен и CSV владельца. Пересчитывается наличная выручка по чекам без размена/внесений/изъятий.
- Переводы RU/EN/HY и общие компоненты для обеих ролей. Устаревшие задачи `useUsers`, `snapshotRead` в Backups и `reportTotals` убраны из оставшегося.

## Что остаётся непроверенным

Запуск сервера и Chrome в песочнице был ограничен; после разрешённого запуска вне песочницы предыдущий implement выполнил MongoDB и браузерные тесты. Отдельный отказ браузерного инструмента для осмотра 4002 остаётся ограничением наблюдения, но по заключению ревью не блокирует согласованную локальную приёмку. Кроме этого, неподтверждены:

- Доставка Web Push на реальные устройства: во всех тестах транспорт `web-push` подменён.
- Планы запросов, задержки и фактическое создание индексов `ledger-indexes-v4` и `audit-indexes-v2` при первом запросе после публикации. Предварительная совместимость проверена чтением Atlas, результаты выполнения миграции фиксируются на release-этапе.
- Облачное расписание резервных копий и настройки Netlify для ветки `barbar`.
- Сквозные браузерные сценарии используют подменённые ответы API и сами по себе не доказывают корректность MongoDB-транзакций; за это отвечает `test:db`.
- После проверок в локальном MongoDB осталась база `barbar_e2e_local` от браузерных тестов. Она синтетическая, рабочих данных в ней нет; её можно удалить вручную.

Рамки и правила — [orders-design.md](orders-design.md). Коммит, публикация и проверка production выполняются отдельным этапом выпуска.
