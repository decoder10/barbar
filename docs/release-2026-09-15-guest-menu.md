# Barbar Cafe — быстрое гостевое меню и планшетный сайдбар, 15 сентября 2026

## Изменения

- `/menu` — отдельная страница `menu.html` (`src/guest.tsx`). Код, стили и шрифты рабочего приложения гость больше не скачивает.
- `/api/menu` предзагружается вместе с HTML; CDN Netlify кеширует ответ (`s-maxage=60`, `stale-while-revalidate=600`, `durable`), новая цена появляется у гостей примерно в течение минуты.
- Последнее меню сохраняется на устройстве и показывается сразу при повторном открытии.
- Стили композиций настоек и сетов перенесены в `_tinctures.scss` и общие для обеих страниц.
- Планшеты (761–1024 px): сайдбар по умолчанию свёрнут в полосу иконок и открывается поверх контента с затемнением.

## Проверки перед публикацией

- `npm run check`: ESLint, TypeScript, 157 тестов прошли; 33 теста с отдельной БД пропущены.
- `npm run build`: успешно.
- Playwright: 54 сценария прошли, включая гостевое меню, мобильные экраны и планшетную ширину. Два сценария входа через локальную MongoDB не прошли: Docker выключен.
- Скриншоты разделов гостевого меню («Коктейли», «Настойки», «Сеты», «Вино») на 390 px совпадают с предыдущей версией production.
- `npm run test:backup` и `npm run test:scheduled-backup` **не выполнены**: нужна локальная MongoDB, Docker выключен. Сервер данных, каталог и резервное копирование в релизе не менялись.

## Публикация и production

Опубликован коммит `2781793`, ветка `barbar`; новая сборка появилась на основном домене примерно через минуту.

- `/`, `/menu` и их ассеты (`main-xDFZ9ZVL.js`, `menu-DVDg-6sW.js`, `photo-catalog-DaEbG9tj.js` и CSS) побайтно совпадают с локальной сборкой.
- Анонимные `/api/barbar` и `/api/barbar/users` — 401, `/api/barbar/auth` — 200 и `authenticated:false`.
- `/api/menu`: первый запрос после деплоя — промах кеша (~3,3 с, холодная функция), далее `Netlify Durable; hit`, TTFB ~0,34 с.
- Загрузка `/menu` при эмуляции мобильной сети (1,6 Мбит/с, 150 мс): первая картинка **1,5 с** (было 2,7 с), сеть затихает через 3,5 с (было 4,2 с); скрипты 134 КБ (было 171 КБ), стили 5 КБ (было 18 КБ). `/api/menu` стартует одновременно с ассетами.
- `npm run probe:latency`: меню — медиана 70 мс, первый ответ 940 мс; auth — медиана 246 мс.
- Планшетный сайдбар на production не проверялся: нужен вход в рабочее пространство. Продажи, закупки и рецепты при проверке не создавались.
