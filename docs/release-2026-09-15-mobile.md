# Barbar Cafe — мобильный интерфейс, 15 сентября 2026

## Изменения

- Нижняя навигация и панель настроек на телефонах.
- Фильтры, выбор категории, действия со складом и история закупок открываются в нижних панелях.
- Продажи за день доступны через закреплённую панель; обновлены компактные экраны владельца и сотрудника.
- Общие диалоги, блокировка прокрутки и переводы EN/HY.
- Браузерная проверка адаптивной сетки ожидает обновления React после смены ширины экрана.

## Проверки перед публикацией

- `npm run check`: ESLint, TypeScript, 157 тестов прошли; 33 теста с отдельной БД пропущены.
- `npm run build`: успешно, основной файл `index-CnTKii5U.js`.
- Playwright: 54 сценария интерфейса прошли, включая мобильные экраны, обе роли и темы. Два сценария входа через локальную MongoDB не завершены успешно: Docker выключен владельцем. По указанию владельца дальнейшая проверка выполняется на production.
- `npm run test:backup`: 502 документа, восстановление типов и индексов, защита от подмены архива — успешно.
- `npm run test:scheduled-backup`: 26 документов, ротация и очистка тестовой базы — успешно.
- `git diff --check` и повторный ESLint — успешно.

## Ограничения

Сервер, данные каталога и миграции в этом релизе не изменены. Новых переменных окружения нет. Настройки резервирования production и сеть Atlas не проверены. `.env.backup` отсутствует, поэтому `db:storage` не выполнен. Проверки резервирования использовали только временные локальные тестовые базы.

Публикация и проверка production фиксируются ниже после завершения деплоя.
