# Barbar Cafe — столы, заказы и оплата, 22 сентября 2026

Опубликован коммит `ede72d3`, ветка `barbar`. Проект и решения владельца: [orders-design.md](orders-design.md); устройство — раздел «Столы, заказы и оплата» в [architecture.md](architecture.md).

## Что вошло

- Доска столов как стартовый экран обеих ролей, экран заказа с общим каталогом продаж и чеком, лист оплаты (наличные со сдачей, карта, перевод, Idram, разделение между гостями), настройка столов у владельца с удалением по подтверждению.
- Строка чека — обычная продажа с `orderId`: остатки, себестоимость, отмены, история и отчёты не изменились. Заказ создаётся с первой позицией; сотрудник убирает строки только из открытого заказа (`removeLine`).
- «Продажи» — журнал дня: касание карточки и «Быстрая продажа» открывают заказ без стола. Полный экран сохраняется между столами, заказом и продажами; в нём есть ссылки «Столы» и «Продажи».
- Модалка «Выпуск заготовки» перерисована, блок с лозунгом в боковой панели убран, `npm run dev` открывает браузер.
- Новые коллекции `tables` и `orders` в резервной копии; индексы `ledger-indexes-v3` создаются при первом запросе к API после публикации.

## Проверки перед публикацией

- `npm run check`: ESLint, TypeScript, 177 модульных тестов (в том числе `domain/__tests__/orders.test.ts`, права сотрудника в `barbar-access.test.ts`).
- `npm run build`: чанки `react` 221,7 / 69,0 КБ gzip, `main` 150,6 / 41,9, `photo-manifest` 100,9 / 21,6, `photo-catalog` 32,4 / 12,2; `index.html` и `menu.html` предзагружают одни и те же общие файлы; `dist/barbar` содержит один JPG.
- Playwright: 58 сценариев, включая `tests/orders.spec.ts` (открытие стола, добавление и удаление строк, разделённая оплата, сотрудник без себестоимости, сохранение полного экрана). Два сценария живого входа не запускались без MongoDB.
- Ревью на дублирование и эффективность (четыре независимых проверки) выполнено до публикации: общие расчёты в `domain/orders.ts`, одна проекция продажи сотрудника, домен без ролей.
- Не запускались: `npm run test:db`, `test:backup`, `test:scheduled-backup`, `test:load` — локальной MongoDB нет, Docker по договорённости не поднимался. Транзакционный тест заказов в `barbar-mongo.test.ts` написан и ждёт следующего запуска базы.
