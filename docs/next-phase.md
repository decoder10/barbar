Функции реализованы и проверены локально. Рабочая публикация ещё не выполнена; облачная часть требует действий ниже. Предыдущие данные не заменяются тестовыми наборами.

## Готово локально

- [x] Аудит MongoDB-индексов по реальным фильтрам и сортировкам: три необходимых добавлены, пять устаревших удаляются безопасной миграцией. Проверены explain и неизменность результатов на 30 000 записей. [Подробности](database-indexes.md).

- [x] AVIF/WebP, адаптивные размеры фото и годовой кеш по хешированному URL; 163 изображения, до −64% по сумме крупных вариантов. Настройка кеша готова для следующего деплоя. [Подробности](menu-images.md).

- [x] Редактирование профиля и роли существующих пользователей, блокировка, новый пароль, отзыв прежних сеансов. Защищён последний активный владелец и гонка двух одновременных блокировок.
- [x] Журнал действий сотрудников: серверный автор, время, операция и описание; фильтры по сотруднику/действию, страницы по 50. Доступ только владельцу. Старые события задним числом не выдумываются.
- [x] Инвентаризация: фактический остаток, расхождение, причина, защита от устаревшего остатка. В интерфейсе позиции пересчитываются по одной; команда поддерживает несколько позиций.
- [x] Списания с причиной и сохранённой себестоимостью, запрет отрицательных остатков.
- [x] Заготовки: расход ингредиентов, выход партии, перенос себестоимости, остаток отдельной готовой позиции, необязательный срок годности. В продаже используется общий остаток заготовки; FIFO/FEFO и отслеживание остатков каждой партии отдельно пока не реализованы.
- [x] Прогноз закупок по расходу выбранного периода, текущему остатку, сроку поставки и резерву. Заготовки отличаются от закупаемых позиций. Автоматических заказов нет.
- [x] Расходы бара: категории, сумма AMD, дата, отмена с сохранением записи. Операционный результат учитывает себестоимость, потери и расходы, закупки дважды не вычитаются.
- [x] Рабочие остатки в `stockBalances`, текущие команды без полного чтения журнала; серверная пагинация и агрегаты отчётов, кеш по revision.
- [x] Нагрузка на 50 000 синтетических продаж: проверены параллельные команды, повторы, остатки и стоимость. Подробности и границы — [performance-2026-09-14.md](performance-2026-09-14.md).
- [x] Зашифрованные копии с компьютера и безопасное восстановление в новую базу; проверены на 502 тестовых документах. [Инструкция](database-backups.md).
- [x] Новые экраны и переводы RU/EN/HY; мобильная раскладка, доступная кнопка выхода, сохранение фильтров.
- [x] ESLint/TypeScript/78 модульных проверок, production build, 30 браузерных сценариев, 17 проверок в команде `test:db`, тест зашифрованного восстановления.
