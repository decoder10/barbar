## Сделано 15 сентября (локально, не опубликовано)

### Склад, меню и рецепты

- [x] **Рецепты снеков**: свои продукты для закусок вместо коктейльных ингредиентов, единица «штуки», пустое количество по умолчанию для веса, предупреждение для сохранённого «не того» ингредиента. Существующие рецепты не переписываются.
- [x] **Группы склада по типу продукта**: крепкий алкоголь, пиво, вино, коньяк, вода и газировка, соки и сиропы, чай и кофе, молоко и сливки, фрукты и ягоды, овощи и зелень, мясо/колбасы/сыр, хлеб и выпечка, снеки, бакалея и соусы, прочее. Те же группы — в выборе ингредиентов рецепта. На телефоне вкладки — выпадающий список.
- [x] **Товары целиком** (газировка, вода, энергетики, чипсы, орехи, чай в пакетиках и т.п.): остаток на складе в бутылках, штуках, граммах или мл, списание за продажу, цена на складе. Такие позиции, а также пиво, вино и коньяк убраны из «Меню и рецептов».
- [x] **Дубли объединены** одноразовой миграцией: неиспользованные дубли удаляются; Тоник, Кола и Содовая объединены с Tonic, Cola, Water — 330 мл за продажу (решение владельца). Позиции с историей не удаляются.
- [x] **Сеты настоек**: выбор настоек и количества шотов, продажа списывает рецепты настоек.
- [x] Редактор позиции: фото в свёрнутом блоке только своей категории, «Дополнительные расходы на порцию» только по смыслу категории и с понятной подсказкой, шрифты окон не меньше 14 px (подписи — 12 px).
- [x] Оригинальные фото: продукты кухни и снеки (Wikimedia Commons с лицензией), вина Vayk и Tushpa Lab, пиво 379 Cherry/Citrus, 1664 Blanc, Волковская IPA, тоник/сливки/Jim Beam Apple от владельца. Источники — в «Источниках фотографий».

## Требует действий владельца

- [ ] **Снять отчёт хранилища** на компьютере с рабочим доступом: `npm run db:storage` (пользователь Atlas только на чтение в `.env.backup`).
- [ ] **Копия рабочей базы и проверка восстановления**: заполнить `.env.backup`, выполнить `npm run db:backup`, `npm run db:verify`, `npm run db:restore`. Для автоматических копий указать `BARBAR_BACKUP_MIRROR_DIR` и установить расписание `npm run db:backup:schedule -- install`.
- [ ] **Сменить раскрытый пароль Atlas**, обновить Production `BARBAR_MONGODB_URI` в Netlify, проверить вход, затем отключить старое подключение. Порядок — в [аудите облака](cloud-security.md). Новый пароль вводит владелец, не в чат.
- [ ] **Оставить рабочий URI только в контексте Production** в Netlify (убрать из Deploy Previews, Branch deploys, Preview Server). Сохранение в интерфейсе требует подтверждения владельца.
- [ ] **Разрешить уведомления на устройствах** и проверить получение push: кнопка «Уведомления» → «Включить push на этом устройстве»; на iPhone — из приложения на экране «Домой». [Инструкция](stock-notifications.md).
- [ ] **Опубликовать изменения 15 сентября** после просмотра: коммит, отправка в `decoder10/barbar`, проверка Netlify. Миграции каталога (товары, объединение дублей, продукты кухни) выполнятся один раз при первом запросе к рабочей БД.
